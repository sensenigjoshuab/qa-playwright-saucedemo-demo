# Upload steps for GitHub repo improvement

Upload these files/folders to the root of your GitHub repository:

- README.md
- package.json
- .gitignore
- tests/saucedemo.spec.js
- .github/workflows/playwright.yml
- playwright.config.js

Do not upload:

- node_modules/
- playwright-report/
- test-results/

After committing, go to the Actions tab and confirm the Playwright Tests workflow passes.

After it passes, the resume/portfolio can truthfully claim GitHub Actions CI verification.
