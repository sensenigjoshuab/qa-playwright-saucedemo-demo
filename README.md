# QA Playwright SauceDemo Portfolio

## Purpose
This project demonstrates entry-level QA automation exposure using Playwright, TypeScript, Page Object Model structure, and GitHub Actions CI.

## What This Shows
- Manual QA understanding
- Functional test coverage
- Positive and negative login testing
- Cart behavior validation
- Checkout completion validation
- Page Object Model organization
- GitHub Actions CI execution

## Test Coverage
| Area | Test Type | Status |
|---|---|---|
| Valid login | Positive functional test | Passing |
| Invalid login | Negative functional test | Passing |
| Add to cart | Functional test | Passing |
| Cart verification | Functional test | Passing |
| Checkout completion | End-to-end test | Passing |

## How to Run
npm install
npx playwright install
npx playwright test

This is a self-directed QA portfolio project using a public demo application. It is not presented as paid QA employment or production framework ownership.
